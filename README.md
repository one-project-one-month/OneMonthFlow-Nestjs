## Project setup

  

```bash

$  npm  install

```

  

## Compile and run the project

  

```bash

#prisma setup command

npx prisma migrate dev --name init
npx prisma generate

# development

$  npm  run  start

  

# watch mode

$  npm  run  dev

  

# production mode

$  npm  run  start:prod

```

  

## Run tests

  

```bash

# unit tests

$  npm  run  test

  

# e2e tests

$  npm  run  test:e2e

  

# test coverage

$  npm  run  test:cov

```
